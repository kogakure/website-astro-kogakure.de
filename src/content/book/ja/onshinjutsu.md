## 隠れる技

隠れている者は、比較的安全に相手を観察し、あるいは好機を待つことができる。だからこそ隠れることは、身を守るおそらく最も有効な方法である。隠れ、身を隠し、偽装し、姿を消す技を**隠身術**といい、隠遁あるいは隠法とも呼ぶ。これは三つの領域に分かれる。

- 光を反射せず、音を立てず、においを出さない
- 相手の見る力と聞く力を奪う
- 変装と演技

出発点は自分自身の感覚である。隠れようとする者は、まず感覚を研ぎ澄まし、色、形、音、距離、においがどう作用するかを試す。そうして初めて互いの関係を理解し、目立たずにいられるようになる。

## 隠法の五つの方法

五大を基礎として、忍者が身を隠すときに用いた原理が生まれた。これは五遁法によく似ている。各領域は厳密には分けられない。どの領域も、別の領域と直接に影響し合っているからである。

### 地

- 大地を利用する
- 地面の穴、窪地、岩の割れ目、あるいは石の陰に隠れる（うずらがくれの術、<q>ウズラのように隠れる術</q>）
- 植物を偽装に使う

### 水

- 水の中や水面下に隠れる
- 人工の葦の島の陰に身を隠す

### 火

- 光、影、音による偽装
- 音を立てずに動く
- 落ちる影と反射に気を配る
- 夕暮れ、霧、雨を偽装に使う

### 風

- 木や柱などの高い場所に身を隠す
- 樹冠に隠れる
- 破風の上に身を隠す

### 空

- 自然の助けが得られないときの偽装
- 身を丸めて岩の塊のように見せる
- 畑の中に身じろぎもせず立ち、案山子のように見せる
- 袋、籠、樽、その他の容れ物の中に身を隠す
- 床下や狭い隙間に隠れる

## 偽装の基本原則

### 偽装にできないこと

偽装は体を隠すが、武器や手投げ弾から守ってはくれない。完全な闇も、それだけで安全を意味するわけではない。相手は暗視装置、赤外線装置、熱画像装置を使うかもしれない。探照灯や照明弾の光の中で見つかったら、身を小さくして動きを止める。

### 衣服と偽装の材料

闇の中に色はない。そのときは明るい赤を着ていても黒を着ていても変わらない。しかし、いつ光が差すかわからないので、暗めの色のほうがよい。不規則な模様と艶のない布地は、深い黒よりもさらに勝る。顔と手も、不規則な模様で偽装する。

自然の偽装材料は頻繁に取り替えなければならない。しおれたり枯れたりした緑は目立つからである。材料はその土地に合ったものを使い、植物が生えているとおりに付ける。葉の裏側は内側に向ける。細布、偽装網、偽装用の飾り紐のような人工の偽装も、自然の植物とほぼ同じように働く。

### 動きと痕跡

薄暗がりでは、素早く慌ただしい動きが居場所を明かす。だから動きはゆっくりと、滑らかにする。急がねばならないときは、地面に低く身を伏せ、短い間だけにとどめる。とりわけ危険なのは、相手の視線を横切る動きである。

広い場所を横切るときは、あらかじめ経路を決め、遮蔽物から遮蔽物へと跳び移り、長くまっすぐ進むことは決してしない。痕跡は残さないか、消し去る。掘り返した新しい土は覆うか運び去る。物や人が落とす影は避けなければならず、光源はいかなる場合にも見えてはならない。

### 探り棒としての鞘

完全な闇の中で、忍者はある工夫によって進む方向を確かめた。刀身の先に鞘をかぶせ、それが落ちないように紐を歯でくわえておく。こうして鞘は探り棒になった。鞘と刀身を合わせた倍の長さのおかげで、触れたものが物であれ人であれ、常にその手の届かない所にいられた。相手に突き当たれば、鞘をただ落とすだけで、すぐに斬りつけられる刀が手の中にあった。

### 時と天候

ある地域は、昼の明るいうちに偵察して地形を頭に入れておくのが最もよい。月夜は監視の任務に、月のない夜は潜入、脱出、戦闘の任務に向いている。雨は自分の立てる音をかき消し、相手の視界を狭める。そのうえ雨の日の見張りは注意が散漫になり、屋外にいることも少なくなる。

### 夜に見る

目が暗さに慣れるには最大で20分かかるが、明るさにはわずか数秒で慣れてしまう。だから白い光を直接見ることは絶対に避けなければならない。地図を読んだり機器を扱ったりするときは赤い光を使う。光が差したら目を覆う。そうしなければ夜目は失われる。

観察は、窪地や地面の穴の中から、地平線を背にした低い位置で行うのが最もよい。闇の中で一点を懸命に見つめると、かえって目標が見えにくくなり、目の前に黒い点が踊っているように見える。視線を目標の周りに巡らせるほうがよい。両手を漏斗のように目の前にかざすと、よく見える。

夜は目を欺く。物は動き、形や色を変えるように見える。物は大きく、距離は遠く見える。反対に、不意に灯る光は近くにあるように見える。

直接に対峙することになれば、煙玉、化学ガス、噴霧剤、目つぶしの粉、強烈な閃光によって、相手の視界を狭めたり、完全に奪ったりできる。

### 聞くことと聞かれること

弱い風のある開けた土地では、音は驚くほど遠くまで届く。

| 距離 | 音 |
| --- | --- |
| 70メートル | 草地を長靴で歩く足音 |
| 100–150メートル | ささやき声 |
| 130メートル | 小枝の折れる音 |
| 150メートル | 野道を長靴で歩く足音 |
| 150メートル | 複数の人の不用意な話し声 |
| 300メートル | 行進する部隊 |
| 600メートル | 杭を打ち込む音 |
| 1,000メートル | 鋤が石に当たる音 |
| 3,000メートル | 車両のエンジン音と履帯の音 |

耳を地面に当てると、よく聞こえる。音の出どころを突き止めるには、頭をその方向に向け、必要なら両手を耳の後ろに添える。

何より大切なのは、自分が音を立てないことである。会話はささやき声だけにするか、まったくしない。手信号で意思を通じ合うほうがよい。

自分の体臭にも気を配らなければならない。人間の感覚の中で嗅覚は最も弱いが、見張りが犬を連れていることもある。だから風下から近づくのが最もよい。
