## 藏身之术

藏起来的人，可以在相对安全的状态下观察，或者等待合适的时机。因此，藏身大概是保护自己最有效的方法。藏身、隐匿、伪装和让自己不被看见的技艺，称为**隐身术**（onshin jutsu），也叫隐遁（inton）或隐法（inpō）。它分为三个方面：

- 不反光，不发出声音，也不散发气味
- 削弱对手看和听的能力
- 乔装和表演

一切都从自己的感官开始。想学会藏身，先要磨炼感官，试一试颜色、形状、声音、距离和气味会产生怎样的效果。只有这样，才能理解其中的关联，避免引人注目。

## 隐法的五种方法

以五大（godai）为基础，形成了一种忍者用于隐匿的原理。它与五遁法（gotonpō）十分相似。这些方面无法严格分开，因为每一个都与另一个直接相互影响。

### 地

- 利用大地
- 藏在地洞、洼地和岩缝里，或者藏在石头后面（*uzura gakure no jutsu*，<q>像鹌鹑一样藏身之术</q>）
- 利用植物伪装

### 水

- 藏在水中或水下
- 藏在人造的芦苇岛后面

### 火

- 借助光、影和声音伪装
- 无声地移动
- 注意投影和反光
- 利用黄昏、雾或雨伪装

### 风

- 藏在树木或杆柱等高处
- 藏在树冠中
- 藏在屋脊山墙上

### 空

- 没有自然遮蔽物可用时的伪装
- 蜷成一团，看起来像一块大石头
- 一动不动地站在田里，冒充稻草人
- 藏在袋子、筐子、桶和其他容器中
- 藏在地板下或夹层空间里

## 伪装的基本规则

### 伪装做不到什么

伪装能遮住身体，却不能保护身体免受武器和手榴弹的伤害。即便是一片漆黑，也不等于安全：对手可能使用微光夜视仪、红外设备或热成像仪。如果被探照灯或照明弹照到，就要把身体缩小，不再移动。

### 衣服与伪装材料

黑暗中没有颜色。这时穿鲜红色还是黑色都无所谓。但光线随时可能照过来，所以深色是更好的选择。不规则的图案和哑光面料甚至比纯黑更好。脸和手也要用不规则的图案伪装。

自然伪装材料必须经常更换，因为枯萎或干枯的绿叶会很显眼。它们必须与所在地区相符，并按植物生长的方式固定：叶子的背面朝里。布条、伪装网和伪装草环之类的人工伪装，效果与自然植被相近。

### 移动与痕迹

在昏暗中，快速而慌乱的动作会暴露自己。因此动作要缓慢而流畅。必须快的时候，就贴近地面，而且时间要短。横穿对手视线方向的移动尤其危险。

要穿过开阔地，就事先规划路线，从一处掩体跃到另一处掩体，绝不长时间沿直线前进。要避免留下痕迹，或者清除痕迹；挖掘出的新土要盖住或运走。要避免物体或人投下的阴影，任何情况下都不能让光源被人看到。

### 用刀鞘探路

在一片漆黑中，忍者用一个窍门辨明方向。他把鞘（saya）套在刀尖上，用牙咬住鞘上的绳带，防止它掉落。刀鞘就成了探杆。刀鞘加刀身，长度翻倍，他用它碰到的东西无论是物体还是人，都始终够不着他。一旦碰到对手，他只需让鞘落下，手中的刀便立刻可以出击。

### 时间与天气

最好在白天就侦察好一片区域，记住地形。有月光的夜晚最适合观察任务，无月的夜晚适合潜入、撤出和战斗行动。雨声能掩盖自己发出的声响，也会限制对手的视线。此外，下雨时守卫会变得不那么警觉，也较少待在户外。

### 夜间视物

眼睛需要长达20分钟才能适应黑暗，适应光亮却只需几秒钟。因此绝对不要直视白光。需要看地图或操作设备时，使用红光。光线照来时要护住眼睛，否则夜视能力就会丧失。

观察时最好从低处对着地平线看，从洼地和地洞里向外看。在黑暗中用力盯住一个点，反而更难看清目标，眼前还会仿佛有一个黑点在跳动。更好的办法是让目光绕着目标转动。把双手拢成漏斗状放在眼前，能看得更清楚。

夜晚会欺骗人的眼睛。物体似乎在移动，形状和颜色也在变化。它们显得更大，距离显得更远；而突然亮起的灯光却显得更近。

如果发生正面冲突，可以用烟雾弹、化学气体、喷雾、致盲粉或强烈的闪光来限制甚至完全剥夺对手的视力。

### 听与被听

微风中，声音在开阔地上能传得出奇地远：

| 距离 | 声音 |
| --- | --- |
| 70米 | 穿靴子走在草地上的脚步声 |
| 100–150米 | 低语 |
| 130米 | 树枝折断声 |
| 150米 | 穿靴子走在土路上的脚步声 |
| 150米 | 几个人不加小心的交谈 |
| 300米 | 部队行军 |
| 600米 | 打桩 |
| 1,000米 | 铁锹碰到石头 |
| 3,000米 | 车辆的发动机声和履带声 |

把耳朵贴在地面上，能听得更清楚。要判断声音的方位，就把头转向声音的方向，必要时把双手拢在耳廓后面。

最重要的是，自己不要发出声音。说话只用耳语，或者干脆不说，用手势沟通更好。

还要注意自己的体味。人的嗅觉虽然是最弱的感官，但守卫可能带着狗。因此最好逆风接近。
