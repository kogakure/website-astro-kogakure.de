# Components

Pages are built only from these components. Add every new component here, with its folder, purpose and props. Every token and component is on `/design-system/`; the design is `DESIGN.md`.

## `site/`: the design system

Astro components, zero JavaScript unless noted. Styles use the role tokens (`src/styles/tokens.css`) and logical properties only.

## `book/`: the book's pages

Plain markup until the templates arrive (SI-474), which compose them from the `site/` components.

| Component         | Purpose                                         | Props                                                                 |
| ----------------- | ----------------------------------------------- | --------------------------------------------------------------------- |
| `BookTitle.astro` | 木隠 as the page heading with the subtitle      | `subtitle` (localised)                                                |
| `Contents.astro`  | Table of contents: front matter, then the parts | `heading`, `introduction` (localised), `parts` (`getToc()`)           |
| `PageText.astro`  | Title, lede and the rendered text (slot)        | `title`, `excerpt`                                                    |
| `BookNav.astro`   | Previous and next page in the book order        | `label`, `previousLabel`, `nextLabel` (localised), `previous`, `next` |

## `ui/`: shadcn/ui on Base UI

Only for interactive parts. Add with `pnpm exec shadcn add <name>`, then point `cn` at `@/lib/utils` (the CLI imports a package `cn`) and restyle to the tokens: 1px corners, roles instead of shadcn's palette, no cards, the defined shadows only.

| Component     | Purpose                                                                           |
| ------------- | --------------------------------------------------------------------------------- |
| `popover.tsx` | Popover, Trigger, Content, Title: the reading paper, a hairline, `shadow-popover` |
