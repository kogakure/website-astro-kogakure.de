# Components

Pages are built only from these components. Add every new component here, with its folder, purpose and props. Every token and component is on `/design-system/`; the design is `DESIGN.md`.

## `templates/`: the page types

Each composes `BaseLayout`, the top bar, the `book/` components and the colophon for one page type in one language. `src/pages/[...route].astro` renders them for every path of `getSitePaths()` and `getBookPaths()`; `src/pages/404.astro` and `src/pages/[lang]/404.astro` render the 404 pages.

| Template             | Page                                                                                                  | Props           |
| -------------------- | ----------------------------------------------------------------------------------------------------- | --------------- |
| `HomePage.astro`     | The homepage: prologue, the ten scenes, colophon                                                      | `lang`          |
| `ContentsPage.astro` | The compact contents (`/inhalt/`, `/en/contents/`, …)                                                 | `lang`          |
| `ArticlePage.astro`  | An article: top bar, opener, reading grid, previous and next, colophon; the glossary with its entries | `lang`, `entry` |
| `NotFoundPage.astro` | The 404 page of a language: opener with its painting, the text, colophon                              | `lang`          |
| `LegalPage.astro`    | Imprint and privacy policy (`src/legal/`), German and English                                         | `lang`, `page`  |

## `ui/`: shadcn/ui on Base UI

Only for interactive parts that HTML cannot do itself: prefer the browser's own `popover`, `<dialog>` and `<details>` first (`SectionPopover.astro`), since an island loads React.

| Component                                                                                                                                                                                                                    | Purpose                                                                                                                                                     | Parts                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `dialog.tsx`                                                                                                                                                                                                                 | Base UI's dialog: the reading paper on a veil of the ground, hairline frame, popover shadow, a short fade (none with reduced motion); focus trap and return | `Dialog`, `DialogContent` (portal, veil, popup), `DialogTitle`, `DialogClose`, `DialogOverlay`, `DialogPortal` |
